# **App Name**: BUConnect

## Core Features:

- User Authentication: Secure authentication system with email and password, supporting student, alumni, and teacher roles.
- Profile Management: Allows users to create and edit profiles with details like name, bio, profession, and college year.
- Post Creation and Management: Enables users to create, like, comment on, and share posts with text, images, or videos.
- User Search: Allows users to search for other users by name, course, or batch.
- Connection Requests: Facilitates connection requests and management between users.
- Role-Based Access Control: Implements role-based access control to manage user permissions for different functionalities.

## Style Guidelines:

- Primary color: Deep blue (#1A5276) to convey trust and professionalism, mirroring an academic environment.
- Background color: Light gray (#F0F4F7), a muted tone from the blue family to maintain a clean and accessible interface.
- Accent color: Soft orange (#E59866), analogous to blue and more saturated, is used for call-to-action elements and important notifications.
- Font: 'Inter', a sans-serif font known for its modern and readable design, used for both headlines and body text.
- Consistent and clear icons to represent different actions and entities within the platform.
- Clean and intuitive layout with a focus on content hierarchy and ease of navigation.
- Subtle transitions and animations to enhance user experience.
